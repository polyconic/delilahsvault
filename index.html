DELILAH'S VAULT

Delilah’s Vault is a 24-hour internet radio station that never stops. Its music plays in one continuous rotation over short clips from the Internet Archive. There is no play button: open it and whatever is on is already in progress, the same for every listener.

The daytime
The same blocks run every day, on the station's own clock. They set the mood of the hour, not the music. The rotation plays straight on through them, reshuffled each time it has been all the way round.
